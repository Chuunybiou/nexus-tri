# Fork state — asymmetric faction RTS

This file is the handoff for anyone (human or Claude Code) picking the fork up. It records
what was changed, why, and the traps that cost time. It travels with the repo.

## What this fork is

An original military-industrial / sci-fi reskin of OpenFront with **three asymmetric
factions**. Inspired by genre classics; names, lore and assets are original on purpose, to
stay clear of anyone's copyright.

| Display name | Code name   | Identity                                                   |
| ------------ | ----------- | ---------------------------------------------------------- |
| Terrans      | `Vanguard`  | Industrial steel. Balance anchor — every modifier neutral. |
| Zorgs        | `Swarm`     | Cheap, fast, numerous. Punished for hoarding.              |
| Protossis    | `Ascendant` | Expensive elites, shields, dependent on a central grid.    |

The UI uses the code names as display names. `Protossis` was judged too close to an existing
trademark and was not used in the interface.

## Done

**Faction data and balance.** `src/core/game/Factions.ts` holds the enum, the per-faction
traits and the scaling helpers. `Config` applies them at exactly four points —
`attackAmount()`, `troopIncreaseRate()`, `goldAdditionRate()` and `costWrapper()` (unit
costs). Measured at equal territory and 100k troops:

|           | Attack | Gold/tick | City cost | Growth |
| --------- | ------ | --------- | --------- | ------ |
| Vanguard  | 20000  | 100       | 125000    | 174    |
| Swarm     | 18000  | 90        | 93750     | 218    |
| Ascendant | 25000  | 110       | 175000    | 139    |

**Signature mechanics**, one `Execution` each, registered in `GameRunner.init()`:

- `SwarmDecayExecution` — troops above 60% of maxTroops rot 4%/s. Asymptotic: it can never
  kill, only punish hoarding.
- `AscendantGridExecution` — Cities are grid nodes. No City = 5%/s treasury drain.
- `AscendantShieldExecution` — units regain 5% of max health per second after 30 undamaged
  ticks, **only while the grid is up**. Cutting the cities is how you fight Ascendant.

**Transport.** `faction` rides `ClientJoinMessageSchema` (the player's request) and
`PlayerSchema` (the server-stamped fact). `PlayerRecordSchema` inherits it, which replays
need — a faction missing there replays as Vanguard and desyncs against recorded hashes.

**Client.** `<faction-selector>` on the play page (persisted via
`UserSettings.selectedFaction()`), `<faction-status>` HUD banner that explains a mechanic
while it is acting on you, `<language-toggle>` EN/FR, `<map-catalog>` listing all maps by
category with click-to-play.

**Visual identity.** Overpass font (was already vendored, nothing declared it), slate base
`#0d1117`, and the three faction colours as the only saturated things in the interface.
Faction emblems are inline SVG. Territory patterns give each faction a blocky texture on
owned ground, reusing the existing cosmetic pattern pipeline.

**Map.** `Anvil Belt`, a space map in the `cosmic` category. Source PNG is generated by
`npx tsx src/scripts/genSpaceMap.ts` (fixed seed, re-runnable to retune), then built with
`npm run gen-maps`.

**Borders.** All bots previously shared ONE colour, so bot-vs-bot borders could not exist.
`classicBotColors` (49-colour pool) now defaults on, and `borderDarken` went 0.125 -> 0.3.

## Not done

In rough value order:

1. **Cities and factories look identical for every faction.** Territory is differentiated,
   structures are not — they render through `StructurePass` / `StructureLevelPass`.
2. **Vanguard has no signature mechanic.** It is defined only as the others' baseline, which
   reads as "the faction with nothing".
3. **No roster asymmetry.** All three build the identical 11 unit types; `PlayerBuildable`
   has no faction filter. This is the gap between "asymmetric numbers" and "asymmetric game".
4. **The space map still uses the earth terrain palette** — green plains, blue water. The
   topology is right, the colours say Earth.
5. **The OpenFront wordmark is unchanged**, so the top-left still reads as the original brand.
6. `resources/lang/fr.json` has ~95 keys missing (pre-existing Crowdin gaps, not from this
   work).

## Traps that cost time

**Use Node 22, not Node 26.** Node 26 defines `localStorage` in `globalThis` with the value
`undefined`, which shadows the one jsdom would install. Every test touching
`UserSettings.getCached` dies — about 900 failures across 69 files, all in `tests/client/`.
They look catastrophic and have nothing to do with your change.

**Three test files fail on a clean checkout** and are unrelated to this work:
`tests/UpdateFlagLatest.test.ts` (runs a bash block from `update.sh`, fails on Windows shell
semantics; imports nothing from `src/`), plus `tests/client/InventoryModal.test.ts` and
`tests/client/MainInitialize.test.ts`, which pass in isolation and only fail under parallel
load. Expect `17 failed | ~6359 passed`.

**A new Lit component that calls `translateText()` must be added to the hardcoded tag list in
`LangSelector.applyTranslation()`**, or it renders raw i18n keys forever. Nothing fails; it
only shows on screen. This bit once already.

**A test player with no tiles is invisible to every Execution**, because `game.players()`
filters on `isAlive()` and `isAlive()` is "owns at least one tile". Conquer tiles in the
helper and assert liveness, or your tests pass for the wrong reason. This bit once already.

**Balance modifiers are integers in per-mille, never float multipliers.** The simulation runs
independently on every client. `applyPerMille` short-circuits at the neutral rate because
`(x * 1000) / 1000` is NOT x for about 2% of doubles — without that, every Vanguard player
would drift off the pre-faction numbers.

**`zbin` has no version byte and no field tags**, so an enum member's index _is_ its
encoding. `tests/FactionWire.test.ts` pins the faction indices as hex vectors; reordering the
enum without updating them silently turns one faction into another between builds.

**The closed-source API is not in this repo.** Everything hitting `localhost:8787` —
cosmetics, JWT refresh, server list, news — fails in dev by design. Singleplayer works.

## Commands

```bash
npm run inst     # install deps (npm ci --ignore-scripts; do NOT use npm install)
npm run dev      # client + server on http://localhost:9000
npx vitest --run # tests
npm run gen-maps # rebuild maps from map-generator/assets (needs Go >= 1.24.4)
```

On Windows PowerShell, `npx`/`npm` may be blocked by the execution policy on `.ps1` shims.
Use `npx.cmd` / `npm.cmd`, or run from Git Bash.
